# AI WORK POLICY — HERO TRAINER

## Contexto
Este projeto utiliza IAs com limites de uso.

## Leitura
- Não ler o repositório inteiro.
- Priorizar documentos de fonte de verdade.
- Ler no máximo 8 arquivos completos por rodada.
- Não repetir leituras sem necessidade.
- Não despejar arquivos completos na conversa.

## Implementação
- Uma fase por vez.
- Não implementar funcionalidades futuras.
- Não fazer refatorações amplas sem necessidade.
- Não duplicar sistemas existentes.
- Preferir alterações pequenas e localizadas.

## Testes
- Testar primeiro a funcionalidade alterada.
- Não executar regressão completa a cada mudança.
- Não executar testes massivos com milhares de seeds.
- Utilizar seeds fixas.
- Preservar a suíte de regressão existente.
- Executar a regressão completa apenas no fechamento da fase.

## Ferramentas
- Não instalar dependências sem necessidade.
- Não criar novos agentes automaticamente.
- Não utilizar APIs pagas em runtime.
- Não realizar pesquisas externas repetitivas.
- Não utilizar Playwright para funcionalidades
  nativas da interface Godot.

## Comunicação
- Respostas objetivas.
- Não repetir o contexto já documentado.
- Não apresentar logs completos.
- Informar apenas alterações, testes, falhas e riscos.

## Segurança
- Nunca apagar alterações do usuário.
- Não executar reset destrutivo.
- Não fazer commit ou push sem autorização.
